# 다음 전개 추천 v2.0.0

SillyTavern의 채팅과 선택한 설정 자료를 바탕으로 다음 플롯을 설계합니다. 기본 출력은 **계기 → 인물의 선택 → 결과**가 드러나는 개요입니다. 추천을 골라 소설 문장으로 확장할 수 있습니다.

## 시작하기

1. SillyTavern을 새로고침합니다. 이전 파일이 남으면 Ctrl+F5를 사용합니다.
2. 확장 메뉴 → 다음 전개 추천 설정 → **이야기 설계**를 엽니다.
3. 빠른 모드(생성 1회) 또는 품질 모드(후보 생성 + 검토, 중복으로 개수가 부족하면 보충 1회)를 선택합니다.
4. 필요하면 새 인물 금지·장소 유지·시간 점프 금지·사용자 캐릭터 선택권을 설정합니다.
5. 전구 버튼으로 생성합니다. 각 후보에서 근거 보기, 문장으로 확장, 이 후보만 수정, 좋아요·아쉬워요를 사용할 수 있습니다.

기존 복사·보내기·직접 편집·합치기·프리뷰·자동 추천 기능도 유지합니다. 프리뷰와 합치기도 본 추천과 동일한 설정 자료·추가 지시·장면 조건·취향을 사용합니다. 문체·감각 묘사는 소설 문장 출력에 적용합니다.

## 맥락과 이야기 기억

- 최근 메시지의 원문 예산을 먼저 확보합니다. 원문에 들어가지 않은 **모든 메시지**를 과거 발췌 후보로 취급합니다.
- 발췌는 전체 줄거리 요약이 아닙니다. 희소한 관련 단어·최근성·서로 다른 메시지를 고려해 선택하며, 예산 때문에 실제 입력에서 제외한 메시지를 표시합니다.
- 긴 최신 메시지는 뒷부분을 보존하고 부분 생략을 표시합니다. 0 예산에서 임의로 기본 예산을 다시 배정하지 않습니다.
- 이야기 설계 → **다음 구간 기억 갱신**은 API 1회로 다음 구간을 처리합니다. 처리 범위를 보며 반복해서 갱신할 수 있습니다. 긴 단일 메시지도 오프셋을 저장해 이어 처리합니다.
- 기억은 확정 사실·인물 목표·관계 변화·미회수 복선·해결된 사건·추측으로 나눕니다. 원문 인용과 메시지 번호가 검증된 항목만 저장합니다. 모델이 만든 해석의 정확성까지 보장하는 것은 아니므로 목록에서 검토·수정·삭제할 수 있습니다.
- 기억은 해당 채팅 메타데이터에 저장됩니다. 원문 전체를 복제하지 않고 변경 확인용 메시지 지문을 저장합니다. 편집·스와이프·분기 뒤 맞지 않는 구간의 기억은 사용하지 않습니다.
- 추천 후보는 기억에 자동 등록하지 않습니다. 실제 채팅에 반영된 내용만 이후 원문 자료가 됩니다.
- 기억은 최대 60개 핵심 항목으로 압축됩니다. 과거 내용을 모두 원문 그대로 읽는 기능은 아닙니다.

## 실제 입력 확인

결과 하단과 이야기 설계 탭의 **이번에 무엇을 읽었나**에서 다음을 확인합니다.

- 원문·발췌·부분 생략·제외된 메시지 번호
- 캐릭터·페르소나·요약·AU·로어북·기억의 포함 및 생략
- 확장이 보낸 실제 프롬프트와 품질 모드의 호출별 프롬프트
- 입력 토큰, 출력 예약, 수집 시간, API 대기 시간, 호출 수, 캐시 사용 여부
- 연결 모델, 적용 가능한 온도, 요청 출력 상한, 취소 방식

총 토큰 예산은 입력과 출력 예약을 합친 값입니다. SillyTavern 토크나이저가 가능하면 사용하고, 실패하면 문자 수 추정임을 표시합니다. 별도 프로바이더/커스텀 모델과 현재 SillyTavern 토크나이저가 다를 수 있습니다. 현재 연결은 전송 전에 SillyTavern이 추가 가공할 수 있으므로 표시값은 최종 공급자 청구량과 같지 않을 수 있습니다.

로어북은 같은 이야기의 직전 생성에서 포착한 실제 활성 항목을 우선 사용합니다. 해당 기록이 없으면 연결된 책의 상시 항목과 현재 키워드에 맞는 항목을 검색합니다. 이 대체 검색은 재귀·확률·시간 효과 등 SillyTavern 전체 규칙을 재현하지 않으며 화면에 대체 검색임을 표시합니다.

## 취향과 다양성

- 좋아요·아쉬워요는 이유와 적용 범위(이번 장면 / 이 작품 / 전체)를 기록합니다. 이유·범위·메모를 수정하거나 기록을 삭제할 수 있습니다.
- 아쉬워요를 눌렀다고 인물 이름이나 앞쪽 단어를 자동 금지하지 않습니다. 기존 자동 키워드는 보관하되 새 추천에 적용하지 않습니다.
- 스펙트럼은 안전/의외/극적의 고정 사다리 대신 인물 선택·복선 회수·관계 변화 등 사건 구조를 다양화합니다.
- 최고 창의성도 기존 사실·세계 규칙·동기를 유지합니다. 조용한 장면을 강제로 깨거나 모든 결말에 새 사건을 요구하지 않습니다.
- 품질 모드는 모델의 의미 검토를 거치고, 로컬 중복 필터는 글자 묶음과 사건 구조 설명의 중복을 추가로 걸러냅니다. 로컬 필터 자체가 의미를 완전히 이해하는 것은 아닙니다.
- 유효한 후보가 부족하면 부족한 개수를 표시합니다. 검증된 인용이 없는 후보도 그 사실을 표시합니다.

## API 및 취소

- **현재 연결:** 설치된 SillyTavern의 `generateRaw`에 `responseLength`를 전달합니다. 채팅 완성 요청은 해당 프롬프트와 일치하는 요청에만 온도·출력 상한을 적용합니다. 모델이 온도를 지원하지 않으면 덧붙이지 않습니다. 텍스트 완성 연결의 온도는 현재 프리셋을 따릅니다.
- 설치된 `generateRaw`는 외부 AbortSignal을 받지 않습니다. 다른 채팅 생성을 중단시키는 전역 stop 이벤트 대신 결과를 폐기합니다. 진행 중인 서버 생성이 끝날 때까지 요청 큐를 점유하며, 취소 즉시 새 요청을 겹쳐 시작하지 않습니다.
- **별도 프로바이더:** 설치된 SillyTavern의 `createGenerationParameters`로 모델별 요청 형식을 구성합니다. Connection Manager 프로필 전환이 아니라 선택한 프로바이더/모델로 요청합니다.
- **커스텀 API:** OpenAI Chat Completions 호환 요청입니다. 해당 서버가 모델·temperature·max_tokens를 지원해야 합니다.
- 별도 프로바이더와 커스텀 요청은 AbortController로 요청 중단을 지원합니다. 네트워크 오류와 408/429/일부 5xx만 최대 2회 재시도하며, 재시도 대기 중에도 취소됩니다. API가 처리한 요청의 비용까지 취소된다는 뜻은 아닙니다.
- 채팅이나 설정이 바뀐 동안 생성된 결과는 현재 화면에 표시하지 않습니다. 캐시는 요청 시작 당시의 전체 입력·설정·연결·채팅 구분으로 저장합니다.
- JSON이 잘리거나 잘못되면 오류로 알립니다. JSON 조각을 추천 문장처럼 표시하지 않습니다.

## 설정 이전

최초 v2 로드 시 새 중첩 설정을 채웁니다. 기존 기본값에 해당하는 4,000 컨텍스트/1,000 출력은 8,000/2,400으로 올리고, 문학적 산문 기본값은 개요 중심 설정으로 전환합니다. 단어 기반 자동 서사 단계 판정과 기존 스펙트럼은 끕니다. 사용자 작성 프롬프트·장르·API 연결 설정은 유지합니다. 변경 전 설정은 `previousSettings`에 API 키를 제외하고 보관됩니다. 별도로 ‘추천 기본값 적용’ 버튼도 제공합니다.

설정 내보내기는 중첩 프로필을 포함해 `apiKey` 필드를 제외합니다. 새 프로필에는 API 키나 취향 기록을 복제하지 않습니다.

## 검증

```sh
node --experimental-vm-modules tests/run.mjs
```

별도 설치 패키지 없이 Node 내장 VM으로 테스트합니다. 실제 소설·계정·API를 사용하지 않습니다. 압축 경계, 긴 메시지, 토큰 예산, 캐시 지문, 취향 범위, 원문 근거, 기억 갱신, 취소 직후 큐 순서, 모델 응답 파싱, 품질 모드 호출 등을 검사합니다.

개발 시에는 격리된 브라우저 화면에서 설정·생성·후보 수정·피드백·기억 편집과 데스크톱/모바일 배치도 확인했습니다. 실제 모델의 문학적 품질은 같은 장면 여러 개에서 수정 전후 결과를 비교해 평가해야 합니다.
